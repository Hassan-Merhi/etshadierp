# ERP Warehouse — Windows Desktop App

Electron wrapper around `https://www.hmdinternationalgroup.com` for distribution via the **Microsoft Store** (MSIX/APPX package).

---

## Quick start

```
npm install          # Install Electron + electron-builder
npm run icons        # Generate all icon sizes from the HMD logo
npm run build:unsigned   # Build MSIX for Store upload (no local signing needed)
```

The package is output to `desktop/dist/*.appx`.

---

## Prerequisites

| Tool | Version | Notes |
|------|---------|-------|
| Node.js | 18 or 20 | Must be **Windows** for MSIX builds |
| npm | 9+ | Bundled with Node.js |
| Windows 10/11 | any | `electron-builder` requires Windows to produce APPX |

> **macOS / Linux cannot build MSIX.** Use Windows locally or the GitHub Actions workflow below.

---

## Step-by-step: local build on Windows

```cmd
cd desktop
npm install
node scripts\generate-icons.js
set CSC_IDENTITY_AUTO_DISCOVERY=false
npm run build:unsigned
```

## Step-by-step: build via GitHub Actions (recommended)

The workflow at `.github/workflows/build-windows.yml` builds on `windows-latest`.

### Trigger option A — push a tag

```bash
git tag desktop-v1.0.0
git push origin desktop-v1.0.0
```

### Trigger option B — manual dispatch

1. Go to **GitHub → Actions → Build Windows Desktop App (MSIX)**
2. Click **Run workflow**
3. Enter the version number (e.g. `1.0.0`)
4. Click **Run workflow**

The workflow uploads the `*.appx` file as a GitHub Actions artifact. Download it from the **Actions → run → Artifacts** section.

## Versioning

| What to do | Command |
|------------|---------|
| Bump patch (1.0.0 → 1.0.1) | `npm version patch` in `desktop/` |
| Bump minor (1.0.0 → 1.1.0) | `npm version minor` in `desktop/` |
| Bump major (1.0.0 → 2.0.0) | `npm version major` in `desktop/` |
| Build specific version | `APP_VERSION=1.2.3 npm run build:unsigned` |

Version in `desktop/package.json` is the single source of truth and is embedded in the MSIX package.

## Microsoft Store — first-time Partner Center setup

You need to do this **once** before uploading.

### 1. Create a Partner Center account

Go to https://partner.microsoft.com/dashboard and sign in (or create) a Microsoft account. Enroll in the **Windows developer program** (one-time $19 registration fee for individuals).

### 2. Reserve the app name

Dashboard → **Create a new app** → enter **ERP Warehouse** → Reserve product name.

### 3. Get your package identity values

Inside the new app → **Product management** → **Product identity**.

Copy these three values and paste them into `electron-builder.config.js`:

| Partner Center label | Config key | Example |
|----------------------|-----------|---------|
| Package/Identity/Name | `appx.identityName` | `12345HMDInternationalGroup.ERPWarehouse` |
| Package/Properties/Publisher | `appx.publisher` | `CN=HMD International Group, O=..., C=US` |
| Package/Properties/PublisherDisplayName | `appx.publisherDisplayName` | `HMD International Group` |

### 4. Edit `electron-builder.config.js`

Replace the three `PLACEHOLDER_` values:

```js
appx: {
  identityName:         '12345HMDInternationalGroup.ERPWarehouse',  // from Partner Center
  publisher:            'CN=HMD International Group, ...',          // from Partner Center
  publisherDisplayName: 'HMD International Group',
  ...
}
```

### 5. Build the MSIX

```cmd
npm run build:unsigned
```

> **No certificate needed.** For Store submission, Partner Center re-signs the package after upload. Local signing is only needed for sideloading/testing outside the Store.

### 6. Upload to Partner Center

1. Dashboard → your **ERP Warehouse** listing → **Start your submission**
2. Fill in: pricing (Free), age rating, privacy policy URL, description, screenshots
3. **Packages** tab → drag-and-drop the `.appx` file from `desktop/dist/`
4. Click **Submit to the Store**

Microsoft reviews the submission (usually 1–3 business days).

## Build script reference

| Script | What it does |
|--------|-------------|
| `npm run start` | Launch the app locally with Electron (requires internet to reach the server) |
| `npm run dev` | Same + opens DevTools |
| `npm run icons` | Re-generate all icon sizes from source logo |
| `npm run build:unsigned` | Build MSIX without local signing — use for Store upload |
| `npm run build:msix` | Build MSIX with local code-signing certificate (sideload/enterprise) |
| `npm run build:installer` | Build `.exe` NSIS installer for direct distribution |

---

## Security notes

- `nodeIntegration: false` and `contextIsolation: true` are enforced — renderer has no Node.js access.
- Navigation is restricted to `*.hmdinternationalgroup.com`; all other URLs open in the system browser.
- `web-contents-created` handler blocks new windows from navigating to external sites.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `appx` build fails on macOS/Linux | Must run on Windows — use the GitHub Actions workflow |
| `Error: ENOENT icons/icon.ico` | Run `npm run icons` first |
| Partner Center rejects the package | Make sure `identityName` and `publisher` match exactly what Partner Center shows |
| App shows "No Connection" screen | The Electron process reached `offline.html` — check internet and server availability |
| `sharp` install fails | Run `npm install --ignore-scripts` then rebuild: `npx sharp-cli rebuild` |
