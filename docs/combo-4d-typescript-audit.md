# Combo 4D TypeScript Audit

## Scope

Combo 4D covers safe TypeScript cleanup in POS, factory stock allocation, factory bale/stock imports, stock-item operations, voucher updates/transfers, and inventory storage. The starting point was `main` commit `73783b83bc8d217aa0e4099ec0d7aff58bfe30b5` after Combo 4C.

## Result

- Starting baseline: **91 diagnostics across 24 files**
- Final baseline: **38 diagnostics across 11 files**
- Removed: **53 diagnostics across 13 files**
- New diagnostics: **0**
- Remaining diagnostics in modified production files: **0**

## Implemented safe slices

### POS types

- Kept nullable exchange rates nullable through POS hook/component boundaries.
- Corrected print-ref types to match nullable React refs.
- Preserved the existing null-to-zero calculation behavior explicitly; no fallback exchange rate or sale-total formula was introduced.

### Factory allocation and import types

- Replaced casts of PostgreSQL `QueryResult` objects with their real `.rows` collections.
- Added precise raw-row types for scanned bales.
- Added explicit product/category map value types and numeric SQL aggregate typing.
- Typed mix-batch ID sets without changing weighted-cost calculations.

### Inventory and location types

- Added the existing current-company guard before location-price lookup.
- Mapped the inventory response's unit alias to the real `uom` field.
- Kept the legacy barcode response key as `null` because `stock_items` has no barcode column; no new barcode semantics were invented.
- Required the location code at the storage boundary and asserted the code already generated by the location route.

### Voucher and stock-operation guards

- Added explicit missing source/destination guards before stock transfer reversal/application.
- Added a post-update not-found guard for vouchers.
- Returned transfer items from the transaction so the existing audit code can access them without a scope error.
- Snapshotted journal entries before passing them to audit change builders.
- Updated the unmerge audit call to the current audit API shape.
- Included the existing `configuredPrice` sales-item field in the typed working array.

## Safety boundary maintained

Combo 4D did **not** change:

- stock quantities or inventory direction
- negative-stock rules
- allocation order or free-to-promise calculations
- transfer quantities, rates, or totals
- voucher totals, Dr/Cr direction, or account selection
- cost, profit, weighted-average, or workbook formulas
- POS item prices or sale totals
- schema or migrations
- TypeScript configuration, `@ts-ignore`, `@ts-nocheck`, or broad suppression casts
