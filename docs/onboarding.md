# Getting Started

## Step 1 — Log In
Go to the app URL, enter your username and password, and select your company from the top-right selector.

> If you don't have credentials, ask your Admin.

---

## Step 2 — Choose Your Mode
The system has two modes accessible from the sidebar:

| Mode | Purpose |
|------|---------|
| **ERP** | Accounting, inventory, purchasing, payroll, POS |
| **Factory** | Bale production, worker management, factory financials |

Your sidebar only shows pages your Admin has granted you access to.

---

## Step 3 — Set Up Your Company (Admin only)
Before entering data, configure:
1. **Settings → Company** — Name, currency, address.
2. **Settings → Locations** — Add your warehouses / shops.
3. **Settings → Users** — Create user accounts and assign page access.
4. **Accounts** — Add opening balances for bank accounts and ledgers.

---

## Step 4 — Core Daily Workflows

### Sell something (POS)
Sales & POS → POS Terminal → Select items → Complete sale.

### Receive inventory
Inventory → Stock Transfers (or Purchasing → Purchase Orders).

### Pay an employee
Payroll → Run Payroll → Select workers → Review advances → Confirm.

### Record a payment or expense
Vouchers → New Voucher → Enter journal entries (debits = credits).

### View financials
Accounts → select an account → view statement.
Daybook → daily summary of all transactions.

---

## Tips
- Use **Ctrl+K** (or Cmd+K) to open the command palette and jump to any page quickly.
- The **dark/light toggle** is in the top-right corner.
- All money amounts respect the company's base currency set in Settings.
- Date format (DD/MM or MM/DD) can be changed per user in Settings → Preferences.
