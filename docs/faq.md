# FAQ

**Can I have multiple companies in one account?**
Yes. Your user account can belong to multiple companies. Switch between them using the company selector in the top-right corner.

---

**Can two users be logged in at the same time?**
Yes. There is no single-session restriction. Changes made by one user are reflected in real-time for others via live updates.

---

**What currencies are supported?**
Any currency can be set as a company's base currency (USD, EUR, GBP, CFA, etc.). Individual voucher entries can also record a different currency for reference.

---

**How do I give a user access to a specific page?**
Go to Settings → User Access Management, select the user, and toggle the pages you want them to see.

---

**Can POS users see cost and profit data?**
No. Cost and profit columns are hidden for POS-role users by design. This is controlled in User Access Management.

---

**How are salary advances tracked?**
Under Payroll → Advances. Each advance records the original amount and remaining balance. When running payroll, outstanding advances are automatically pre-filled as deductions.

---

**Can I export data?**
Yes. Most pages have an Export button that downloads an Excel or CSV file. Account statements can be printed or exported as PDF.

---

**Is data separated between companies?**
Yes. All transactions, employees, accounts, and inventory are company-scoped. Suppliers are the only shared (global) entity.

---

**How do I undo a voucher?**
Open the voucher and delete it (if not yet paid/finalized). Deleted vouchers are soft-deleted and excluded from all reports.

---

**What happens if the server restarts?**
The database persists all data. The server re-runs auto-migrations on startup. No data is lost on restart.

---

**Is there a mobile app?**
No. The system is a web app with a responsive layout that works on mobile browsers.
