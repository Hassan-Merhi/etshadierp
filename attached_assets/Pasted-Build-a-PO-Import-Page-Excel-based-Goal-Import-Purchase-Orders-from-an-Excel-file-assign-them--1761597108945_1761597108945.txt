Build a “PO Import” Page (Excel-based)

Goal
Import Purchase Orders from an Excel file, assign them to a Container Number, post the total value to the Supplier’s account, show them on a Container OTW page, and support extra accounts/charges (freight, surcharge, fumigation, discount, doc charges, etc.). Allow item lookup by Barcode or Name; if barcodes are used, convert to names on import (no codes visible after import).

1) UI Flow

Upload Excel (.xlsx).

Select/confirm: Supplier, Container Number (or enter new), Import Date.

Preview grid → shows items with Name, Qty, Rate, Line Total, plus Extra Accounts lines.

Actions: Validate, Import, Cancel.

After import: redirect to Container OTW detail page (read-only), plus link to Supplier ledger entry.

2) Excel Template (Columns)

Header row required. Support either Barcode or ItemName per row.

Required columns:

PO_Number

Container_Number

Supplier_Code (or choose supplier in UI and ignore this column)

Item_Barcode (optional if using Item_Name)

Item_Name (optional if using Item_Barcode)

Quantity

Rate

Currency (optional; default org currency)

Optional extra charges (any/all may appear as separate rows OR extra columns):

As rows: Charge_Type, Charge_Amount (e.g., “Freight”, “Surcharge”, “Fumigation”, “Discount, Document_Charges`)

OR as columns on item rows: Freight, Surcharge, Fumigation, Discount, Document_Charges (numbers)

Keep it simple: we’ll support either charge-rows or per-row charge-columns. If both appear, prefer charge-rows.

Example (rows format)

PO_Number,Container_Number,Supplier_Code,Item_Barcode,Item_Name,Quantity,Rate,Charge_Type,Charge_Amount
PO-1001,CNTR-88,SUP-ALPHA,8901234567890,,10,5.50,,
PO-1001,CNTR-88,SUP-ALPHA,,, , ,Freight,120
PO-1001,CNTR-88,SUP-ALPHA,,, , ,Fumigation,40


Example (columns format)

PO_Number,Container_Number,Supplier_Code,Item_Barcode,Item_Name,Quantity,Rate,Freight,Surcharge,Discount,Document_Charges
PO-1002,CNTR-88,SUP-ALPHA,8901234567890,,10,5.50,50,0,0,10

3) Barcode → Name Mapping

Before validating, map Item_Barcode to the system’s Item Name via Items master (barcode -> itemId -> itemName).

If both barcode and name are present, trust barcode and overwrite name from master.

On preview/import, only show the item name (no barcodes). Store itemId internally.

4) Calculations

Line Total = Quantity * Rate.

PO Total = Sum of all item line totals for the PO.

Container Total = Sum of all POs under the same Container_Number in the file.

Extra Accounts:

If provided as rows: add each Charge_Amount to the Container Total.

If provided as columns: sum each charge column across rows and add to Container Total.

Grand Total (for posting to Supplier) = Items Total + All Extra Charges − Discounts.

(Optional) Allocation method for charges to items: None (keep at header level) to keep it simple.

5) Posting Rules

On successful import:

Create Container record (if new) with status “OTW”.

Create PO records linked to the Container.

Create GRN placeholder (optional, not received yet).

Post one Supplier ledger journal:

Debit: Inventory / Goods In Transit (or a “Purchases” interim account).

Debit: Extra charges (Freight, Fumigation, etc.) to respective expense/clearing ledgers.

Credit: Supplier Payable for the Grand Total.

Store a checksum/idempotency key for the file (e.g., hash of rows) to prevent duplicate imports.

6) Validation (basic)

Must have either Item_Barcode or Item_Name on each item row.

Quantity > 0, Rate ≥ 0.

All barcodes must exist in Items master (if not, show an error list).

Supplier must exist (or be selected in UI).

Container required. If rows have mixed containers, allow multi-container import but group by container in preview.

If charge rows present: Charge_Type required and recognized; Charge_Amount ≥ 0.

If charge columns used: numbers ≥ 0.

Prevent re-import by checking idempotency key.

7) Container OTW Page

Header: Container Number, Supplier, Status “OTW”, Import Date.

Table:

Item Name | Qty | Rate | Line Total

Section: Extra Accounts (Freight, Surcharge, Fumigation, Discount, Document Charges) with amounts.

Footer totals: Items Total, Charges Total, Grand Total.

Links: View POs included, View Supplier Ledger Entry.
