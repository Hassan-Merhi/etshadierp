What this usually means
Case A) The request is actually sent but stays Pending

Common causes:

backend endpoint never responds (server stuck)

request is waiting on DB lock / transaction

wrong URL / proxy causing a connection hang

no timeout configured (so it “waits forever”)

Case B) The request is never sent

Common causes:

apiRequest() doesn’t return fetch(...) / return axios(...)

missing await inside apiRequest

apiRequest throws synchronously before the fetch (but your code doesn’t catch/log it)

request blocked by CORS/preflight (you’ll see it in Network)

The #1 code bug that causes exactly your “last log then nothing”

Inside your mutationFn you likely have something like:

console.log("About to call apiRequest")
apiRequest("/vouchers", payload)  // <-- not returned / not awaited
console.log("After apiRequest")   // never logs


✅ Correct pattern:

console.log("About to call apiRequest")
const res = await apiRequest("/vouchers", payload)  // await
console.log("apiRequest returned", res)
return res  // IMPORTANT for react-query mutation


If you don’t return the promise, React Query can behave weirdly and your UI can stay in “Saving…”.

Add these 3 logs (this will pinpoint it instantly)

Put them inside the mutationFn, around the apiRequest line:

console.log("[StockTransfer] D3-1 calling apiRequest...");

try {
  const result = await apiRequest(...);
  console.log("[StockTransfer] D3-2 apiRequest result:", result);
  return result;
} catch (err) {
  console.log("[StockTransfer] D3-ERR apiRequest error:", err);
  throw err;
}


If you only see D3-1, then the promise is hanging (Network Pending) or apiRequest never resolves.

Most likely fix in apiRequest

Check your apiRequest function for these issues:

✅ It must return the fetch/axios promise
return fetch(url, options)

✅ It must await .json() safely

If backend returns empty body, await res.json() can hang/throw.
Use:

const text = await res.text();
const data = text ? JSON.parse(text) : null;

✅ Add a timeout (prevents infinite “Saving…”)

If using fetch:

const controller = new AbortController();
setTimeout(() => controller.abort(), 15000);

await fetch(url, { signal: controller.signal, ... })
